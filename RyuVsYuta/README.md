# Рю Ишигори ✕ Юта Оккоцу — анимация боя в Roblox

Покадровая анимация боя из «Магической битвы» (Игра смерти, колония Сендай) по видео-референсу.
Бой делается **по этапам**; сейчас готов **Этап 1 — «Из тумана»** (начало боя, ~24 с).

## Как посмотреть

1. Скачай **`RyuVsYuta.rbxl`** из корня репозитория.
2. Открой в **Roblox Studio** (File → Open from File).
3. Нажми **Play** (F5). Появится стартовый экран — нажми **«▶ ЗАПУСТИТЬ АНИМАЦИЮ»**.

Игрок **не** превращается в персонажа: персонажа у игрока нет, камерой управляет катсцена.
Сцену (руины, туман, модели) видно и без запуска — прямо в редакторе.

### Управление во время просмотра

| Клавиша | Что делает |
|---|---|
| Пробел | пауза / продолжить |
| ← / → | перемотка на 2 секунды |
| 1 / 2 / 3 | скорость 0.25× / 0.5× / 1× |
| R | смотреть сначала |
| H | скрыть / показать панель |
| Клик по таймлайну | перейти в нужный момент |

На панели внизу видно время (например `07.4 / 24.2 с · Кадр 1 — дым, Рика и Юта`) — по нему удобно
писать замечания: «на 8.5 с Рика слишком быстро», «в кадре 3 камеру ближе» и т. п.

## Что в Этапе 1

| Время | Кадр | Что происходит |
|---|---|---|
| 0 – 12 с | **1. Дым** | Хвост взрыва Granite Blast, камера низко плывёт сквозь густой дым. В дыму проступает силуэт, вспыхивает красный глаз Рики, проступают контуры; Рика (без ног — внизу чёрная дымная масса) медленно надвигается тяжёлыми толчками, грива вздымается вверх, перед ней между её рук идёт Юта. |
| 12 – 15 с | **2. Рю** | Снизу, на фоне огромных облаков-клубов дыма: широкая стойка, руки на отворотах куртки, по воротнику вверх — и с хлопком на помпадур. Куртка и мех треплются на ветру. |
| 15 – 21.2 с | **3. Помпадур** | Крупно снизу: голова опущена, помпадур «дулом» в объектив, ладони ведут волосы назад. Беззвучно загорается кончик — нарастание — **«дзынь»**: синие разряды по помпадуру и лбу, вспышка, голова вскидывается, ухмылка. Субтитр «Ну что ж…». |
| 21.2 – 24.2 с | Титр | «ЭТАП 1 · ИЗ ТУМАНА». |

Тайминг всех событий — в одном файле: `src/shared/Sequence/Timing.luau`.

## Как это сделано (коротко)

- **Модели** собраны кодом из деталей Roblox (эллипсоиды `SpecialMesh`, блоки, клинья, цилиндры) — без
  загружаемых мешей: файл открывается у любого. Волосы и мех — пряди из `Beam` с контуром; аниме-контур
  фигур — `Highlight`.
- **Анимация** — свой скелет (кости, прямая кинематика + IK рук и ног), позы по ключевым кадрам со
  сглаженными сплайнами, процедурная ходьба, дыхание, колыхание волос/меха от ветра. Всё — функция времени,
  поэтому работают пауза, перемотка и замедление.
- **Туман** — плотная `Atmosphere` + десятки эмиттеров дыма разной высоты (стена дыма, низовой туман,
  дымка у Рю) + клочья дыма, пролетающие у самого объектива; плотность меняется по ходу сцены.
- **Свет** — технология Future, цветокоррекция и свечение по кадрам, глубина резкости, вспышка энергии
  подсвечивает лицо.
- **Звук** — ~25 звуков из Магазина Roblox (лицензированные библиотеки ProSoundEffects / APM / Roblox),
  каждый скачан и измерен (громкость LUFS, спектр, начало без тишины). Фоновые петли (ветер, гул дыма,
  музыка, треск энергии, хлопанье куртки) с огибающими громкости, разовые звуки по таймлайну, группы с
  реверберацией и компрессором. Если какой-то ID недоступен — подставляется запасной.

## Для разработчиков

```bash
../tools/setup.sh        # один раз: Rojo, Lune, luau-lsp в ../.tools/
tools/build.sh           # тесты -> строгий анализ типов -> Rojo -> сборка моделей (Lune) -> проверка места
```

- `src/shared/Sequence/` — сцена: `Timing` (время), `Actors` (игра персонажей), `Cameras`, `Atmos`
  (туман, свет, интерфейс), `Sequence` (сборка кадра, звуковые события).
- `src/shared/Builders/` — строители моделей и окружения, `src/shared/Proportions/` — пропорции скелетов.
- `src/client/` — режиссёр (часы, пауза, перемотка), драйвер персонажей, эффекты, звук, интерфейс.
- `tools/previz_*.luau` + `tools/previz_render.py` — превиз: рендер кадров сцены вне Roblox для проверки
  поз и кадрирования.
