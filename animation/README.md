# Юта vs Рю — анимация в Roblox (часть 1)

Проба стилей: первые **3 секунды** ролика «Yuta vs. Ryu end fight scene pt. 1», сделанные в трёх стилях.
Выбери стиль — дальше вся часть 1 (58 секунд) делается в нём.

## Как посмотреть

1. Скачай **`YutaVsRyu_StyleTest.rbxl`** из этой папки.
2. Открой в **Roblox Studio** (File → Open from File).
3. Нажми **Play (F5)** — сцена соберётся и анимация запустится сама.

| Клавиша | Что делает |
|---|---|
| `1` / `2` / `3` | стиль: Аниме / Кино / Классика (с начала) |
| `A` | все три стиля подряд, с титрами (удобно записать одним видео) |
| `R` | заново |
| `Пробел` | пауза |
| `←` / `→` | на кадр назад / вперёд (1/30 с), на паузе |
| `L` | повтор вкл/выкл |
| `H` | скрыть/показать подсказку (для чистой записи) |

Картинка всегда 16:9: если окно другой формы, по краям будут чёрные полосы, а кадр не обрежется.
Записывать удобно через OBS или встроенную запись Roblox, предварительно скрыв подсказку клавишей `H`.

Превью без Studio лежат в [`preview/`](preview/). Это приблизительный рендер вне Roblox:
свет, туман и материалы в Studio будут немного отличаться. Точный вид — в `.rbxl`.

## Стили

1. **Аниме.** Плоская заливка, чёрные контуры персонажей (Highlight), мягкий свет без теней, холодный синий цветокор и рисованное грозовое небо. Ближе всего к оригиналу.
2. **Кино.** Реалистичный свет с мягкими тенями, настоящие облака Roblox и атмосферная дымка, глубина резкости на общем плане, падающий снег, виньетка, приглушённые цвета и мягкая светотень на лицах.
3. **Классика.** Яркий «роблоксовский» пластик, солнце, голубое небо с облаками, снег со «стадами» (studs), сочные цвета.

## Что в этих 3 секундах

Тайминг и движение сняты с оригинала покадрово (30 к/с):

- **0.000–0.867 с — общий план.** Снежная равнина в тумане. Слева Рю указывает пальцем, справа пригнулась Рика, за ней стоит Юта. Позиции и размеры фигур рассчитаны так, чтобы они стояли в тех же точках кадра, что и в оригинале.
- **0.867–3.000 с — сплит-экран.** Сверху глаза Юты, снизу глаза Рю, между ними чёрная полоса. Лица въезжают с разных сторон, тормозят по измеренной кривой и продолжают медленно ползти (≈ ±11 px/с), как в оригинале.

## Как это сделано

- **Персонажи** — R15-скелеты (стандартные имена частей R15), собранные из деталей: у Рю помпадур, чёрная шуба с белым мехом и жетоны, у Юты белая форма, тёмные волосы и катана за спиной, у Рики белое тело, длинные руки с когтями и грива из шипов.
- **Аниме-глаза** нарисованы обычными UI-элементами Roblox (Frame + UICorner + UIGradient) на SurfaceGui: тонкие линии с утончением, радужки, блики и тени. Картинки не загружаются, всё работает в локальном файле без публикации.
- **Анимация** — детерминированный таймлайн: каждый кадр вычисляется строго по времени `t`. Поэтому работают пауза, перемотка по кадрам и повтор, а запись всегда получается одинаковой.
- Сцена создаётся на клиенте при нажатии Play. В редакторе виден только щит с подсказкой.

## Структура

```
animation/
  YutaVsRyu_StyleTest.rbxl   готовое место для Roblox Studio
  default.project.json       проект Rojo
  preview/                   MP4-превью трёх стилей
  src/Cutscene/              модули: движок, стили, персонажи, лица, сцены, таймлайн
    Shots.luau               таймлайн и измеренные кривые движения
    Styles.luau              три стиля: палитры, свет, атмосфера, постобработка
    Art/Characters/          Рю, Юта, Рика
    Art/Faces/               крупные планы глаз
    Art/Sets/                общий план, сплит-экран, небо и туман
  src/Player/                LocalScript-проигрыватель (клавиши, камера, полосы 16:9)
  tools/                     сборка, проверки, рендер превью
```

## Сборка из исходников (для разработчиков)

```bash
../tools/setup.sh                  # Rojo, Lune, luau-lsp в ../.tools/
tools/build.sh                     # анализ типов -> проверка объектов -> .rbxl -> проверка места
(cd tools/preview && npm install)  # three.js для превью
tools/preview/make.sh 1280 720     # MP4-превью всех стилей в build/preview/
```

Проверки:

- строгий анализ всего Luau-кода с типами Roblox API (`luau-lsp`);
- сборка всех трёх стилей настоящим кодом `Realizer` в модели данных Lune, где каждое свойство сверяется с базой Roblox;
- проверка собранного `.rbxl`.

Запустить сам Roblox Studio в облачном окружении нельзя, поэтому финальный вид нужно проверить в Studio.
