# Юта vs Рю — анимация в Roblox, часть 1

Полная часть 1 (58.5 с) ролика «Yuta vs. Ryu end fight scene pt. 1» в выбранном стиле **«Кино»**:
реалистичный свет, облака Roblox и дымка, глубина резкости, падающий снег, неоновые эффекты с bloom.
Все 38 планов повторяют раскадровку и тайминг оригинала (склейки найдены покадрово).

## Как посмотреть

1. Скачай **`YutaVsRyu_Part1.rbxl`** из этой папки.
2. Открой в **Roblox Studio** (File → Open from File).
3. Нажми **Play (F5)**: сцена соберётся за пару секунд, и анимация запустится сама.

| Клавиша | Что делает |
|---|---|
| `R` | с начала |
| `Пробел` | пауза |
| `←` / `→` | на кадр назад / вперёд (1/30 с) |
| `J` / `K` | на план назад / вперёд |
| `S` | субтитры вкл/выкл |
| `L` | повтор вкл/выкл |
| `H` | скрыть/показать подсказку (для чистой записи) |

Картинка всегда 16:9: при окне другой формы по краям будут чёрные полосы, кадр не обрежется.
Записывать удобно через OBS или встроенную запись Roblox, предварительно скрыв подсказку клавишей `H`.
Звука нет: музыку и голоса накладываешь при монтаже. Английские субтитры совпадают по времени с оригиналом
(выключаются клавишей `S`).

Превью без Studio: [`preview/part1_preview.mp4`](preview/part1_preview.mp4). Это приблизительный рендер вне Roblox:
свет, облака и материалы в Studio будут выглядеть немного иначе. Точный вид — в `.rbxl`.

## Как это сделано

- **Персонажи** — R15-скелеты из деталей. У Рю помпадур, чёрная шуба с белым колючим мехом, открытая грудь и жетоны. У Юты белая форма с высоким воротником, кровь на плече, катана. Рика сделана по присланному рисунку: тощий скелет с рёбрами, вытянутый череп с зубастой ухмылкой, белые пряди назад, длинные руки с когтями, чёрный дымчатый хвост вместо ног.
- **Лица** нарисованы UI-элементами Roblox (Frame + UICorner + UIGradient) на SurfaceGui головы, с мимикой: ухмылка, смех, разговор, злой прищур. Картинки не загружаются, всё работает в локальном файле.
- **Эффекты** — неоновые детали с bloom (лучи, молнии, осколки, ядро взрыва, ударные волны), точечные источники света, частицы (искры, снег), 2D-слои (сплит-экран, вспышки, линии скорости, ветер).
- **Анимация** — детерминированный таймлайн: каждый кадр вычисляется строго по времени `t`. Поэтому работают пауза, перемотка и переход по планам, а запись всегда одинаковая.

## Структура

```
animation/
  YutaVsRyu_Part1.rbxl     готовое место для Roblox Studio
  default.project.json     проект Rojo
  preview/                 MP4-превью
  src/Cutscene/            движок (Timeline, Rig, Paint, FX, Realizer…), стиль, сцены и планы
    Shots/                 Cast (персонажи), Field (ледяное поле), Opening, Clash, RyuShots, YutaShots
    Art/Characters/        Рю, Юта, Рика
    Art/Faces/             лица с мимикой и сплит-экран глаз
  src/Player/              LocalScript-проигрыватель
  tools/                   сборка, проверки, рендер превью, лаборатория персонажей
```

## Сборка из исходников (для разработчиков)

```bash
../tools/setup.sh                  # Rojo, Lune, luau-lsp в ../.tools/
tools/build.sh                     # анализ типов -> проверка объектов -> .rbxl -> проверка места
(cd tools/preview && npm install)  # three.js для превью
# превью всей части: кадры построчно (JSONL), рендер потоком, затем MP4
../.tools/lune run tools/export.luau build/part1.jsonl 30
node tools/preview/render.cjs build/part1.jsonl build/frames 1280 720
ffmpeg -framerate 30 -i build/frames/f_%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 build/part1_preview.mp4
# сравнение с оригиналом бок о бок
tools/preview/compare.sh <оригинал.mp4> build/part1_preview.mp4 build/compare.mp4
# отдельные моменты сцены: времена через запятую
../.tools/lune run tools/shotlab.luau build/lab.json 0.4,9.0
# ...или с наездом камеры на точку x,y,z и своим FOV
../.tools/lune run tools/shotlab.luau build/lab.json 0.4 25,4,-119 9
node tools/preview/render.cjs build/lab.json build/lab 960 540
```

Проверки:

- строгий анализ всего Luau-кода с типами Roblox API (`luau-lsp`);
- сборка сцены настоящим кодом `Realizer` в модели данных Lune, где каждое свойство сверяется с базой Roblox;
- проверка собранного `.rbxl`.

Запустить сам Roblox Studio в облачном окружении нельзя, поэтому финальный вид нужно проверить в Studio.
