# Код Мультивселенной

Пиксельная игра в стиле Undertale. Ты стажёр Профессора Клода и с нуля учишься писать
код для Roblox (язык Luau), чтобы спасти мультивселенную от вируса Глюк.

**Играть:** https://claude.ai/artifact/QcwFSW6nyktfwFgTJtdQ7G (открывается на телефоне)

Без ссылки можно открыть файл `index.html` в браузере телефона. Живой Клод в чате работает
только по ссылке выше, а в файле он в офлайн-режиме и понимает простые команды.

## Что внутри

- 7 миров: Гараж, Планета Слизи, Лес Условий, Городок Петля, Фабрика Функций, Кубоград, Ядро Глюка.
- 10 уроков: `print` → переменные → числа → `if` → циклы → функции → таблицы →
  `Instance.new("Part")` → события `Touched`/`ClickDetector` → монеты и `leaderstats`.
- Редактор кода с кнопками для скобок и кавычек. Код по-настоящему запускается
  (Lua в браузере + мини-Roblox: детали, гравитация, персонаж, лидерборд), окно «Мир» показывает детали.
- Домашки: делаешь в редакторе, нажимаешь «Проверить», потом показываешь Клоду в мире.
- Бои: БОЙ / КОД (вопросы по урокам) / ВЕЩИ / ПОЩАДА, уворот сердечком. Клод сражается вместе с тобой.
- Чат 💬 с живым Клодом: объясняет код и может менять игру (скорость, погода, шляпы,
  сложность, новые враги и персонажи, телепорт, новые домашки).

## Сборка

```
node claude-quest/build.mjs
```

Исходники в `src/`. Скрипт собирает их в `index.html` (обычная страница) и в `dist/artifact.html` (для публикации).
