# Aura Farmer — руководство для исполнителей (агентов)

Роблокс-ролик по клипу «Aura Farmer» (15.6 с, 11 планов). Всё собирается кодом в `AuraFarmer.rbxl`.
Работать только в `aura-farmer/`. Инструменты: `../.tools/lune`, `../.tools/rojo`.

## Структура

## Системы координат

* Мир: Roblox (+Y вверх). Декорации разнесены: `Config.Sets` (Beach (0,0,0), Park (0,0,9000), Gym (9000,0,9000), Throne (-9000,0,9000)).
  Земля каждой декорации — на локальной высоте Y=0. `Config.at(set,x,y,z)` и `Config.place(set,x,z,yaw)` переводят локальные координаты в мир.
* Персонаж («char space»): начало на земле между стопами, +X — вправо от персонажа, +Y — вверх, **−Z — вперёд**.
  `Config.place(..., yaw=0)` — смотрит в −Z; yaw=180 — в +Z; yaw=90 — в −X.
* В DSL поз точки пишутся `{x, y, f}`, где **f — вперёд** (компилятор сам делает z = −f).
* Если камера смотрит персонажу в лицо, его правая рука (+X) — **слева** в кадре.
* Камера Roblox: `FieldOfView` — **вертикальный** угол. Кадр 16:9.

## Риг и детали

* Скелет: невидимые кости R15 (HumanoidRootPart, LowerTorso, UpperTorso, Head, Right/LeftUpperArm, LowerArm, Hand, UpperLeg, LowerLeg, Foot)
  + пальцы у коня (Right/LeftIndex1/2, Middle, Ring, Pinky, Thumb) + доп. суставы (Jaw, Glasses, Brow, Ear, UpperLip, Mane, предметы).
* Видимая геометрия — через `rig:part / ellipsoid / box / ball / cyl` (координаты — char space в позе покоя; деталь приваривается к кости).
* Доп. сустав: `rig:joint(name, parentBone, pivot, center, size)` и детали на него. Лицевые каналы — `rig.face`.
* Разрешённые формы: Part Block/Ball/Cylinder/Wedge/CornerWedge и SpecialMesh Sphere/Cylinder/Head/Wedge/Brick.
* **ВАЖНО: на детали со SpecialMesh Roblox НЕ показывает Material** (ни текстуры, ни металл, ни стекло, ни неон) —
  она выглядит как гладкий пластик цвета Color. Поэтому золото (цепь, пряжка, кольца, часы, оправы), стекло линз,
  неон, ткань с фактурой — делать настоящими формами Part (Ball — только шар, Cylinder — круглое сечение, Block, Wedge)
  с нужным Material. SpecialMesh Sphere (эллипсоиды) — для органики, где важен только цвет (мех, кожа, губы).
  Превью уже показывает это так же (эллипсоиды без материала).
  Никаких MeshId/TextureId/загруженных ассетов (должно работать из файла офлайн). Материалы — встроенные Enum.Material.
* Не делать детали с совпадающими гранями (z-fighting): сдвигайте на ≥0.01–0.02 студа.

## Анимация (tools/anims/SXX.luau)

```lua
return {
  Horse = { keys = {
    { t = 3.90, neck = { turn = -60 }, rArm = { ik = { 0.9, 4.6, 0.3 }, pole = { 1, -1, -0.5 } }, rHand = "thumb", face = { jaw = 0.4 } },
    { t = 4.20, ease = "Back_Out", neck = { turn = 0, nod = -5 } },
  } },
}
```
* `t` — абсолютное время ролика. Ключи можно ставить чуть до начала/после конца плана (для касательных).
* По умолчанию сглаживание `smooth` (сплайн без перелётов на экстремумах). Есть `linear`, `hold`, `inout`, `in`, `out`, `Back_Out`, `Elastic_Out`, `Sine_InOut` и т.п.
* Группа в ключе задаётся целиком (пропущенные поля = 0). Не заданная группа интерполируется между ключами, где она задана.
* IK: `space = "body"` (по умолчанию, неподвижно относительно мира в плане), `"hips"`, `"chest"`, `"head"` (точка в позе покоя «едет» с костью).
* Анимация запекается в `ServerStorage.RBX_ANIMSAVES.<План>_<Актёр>.<План>` (KeyframeSequence) — её можно открыть в Animation Editor.

## Постановка (контракт между декорациями и планами)

Координаты — локальные для декорации (Y=0 — земля/пол). Зона постановки вокруг (0,0,0) должна быть свободна.

**Beach** (пляж Схевенинген, Нидерланды):
* Песок (Terrain Sand) верх на Y=0: x∈[-700,700], z∈[-160,520]; мокрая полоса у воды темнее. Море (Terrain Water) при z < -160 до горизонта (≥3000 студов), уровень воды ≈ -0.6.
* Город/набережная на юге: z ≈ +330…+650, многоэтажки 30–110 студов, белый павильон-«шатёр», фонари, флаги; по песку редкие маленькие фигурки людей вдали.
* Пирс (Pier Scheveningen): от берега около x=+160 уходит в море по −Z до z≈-700, настил на высоте ≈10–12 на сваях-опорах, на конце — постройки; виден в S02/S04/S06 справа-сзади.
* Следы шин и вмятины на песке у зоны постановки.

**Park** (лужайка в городском парке):
* Трава (Terrain Grass, Decoration) верх Y=0 на 500×500. Персонаж в (0,0,0) смотрит в −Z, камера обычно в −Z и смотрит на +Z.
* Позади (z≈+22…+30) — ряд стриженой живой изгороди (≈2.5 высотой); деревья по бокам и сзади (z +25…+80, x ±15…±60), высокие лиственные кроны; за ними современное офисное здание со стеклом (z≈+150).

**Gym** (спортзал с фиолетовым неоном):
* Комната: пол Y=0 (тёмная резина), x∈[-20,20], z∈[-26,16], потолок Y=12 (тёмное дерево/рейки) с диагональными неоновыми полосами фиолет/розовый, точечные светильники.
* Скамья под конём: центр (0,0,0.4), длинная ось вдоль Z, длина 3.6, ширина 1.1, **верх сиденья Y=1.55**. Конь сидит на переднем конце, лицом в −Z.
* (как построено по кадру S10) Стойки с гантелями ближе к камере: z≈+0.5…+6.4 (внешние концы ближе, внутренние концы ≈ x −2.6 и +4.4),
  перегородки: слева в кадре (+X) z=8 с зеркалом, справа (−X) z=10.8; между ними коридор |x|<7 до z=36. Статисты стоят у стоек: z≈+0.5…+2.5
  (рыжая девушка слева в кадре — со стороны +X коня, char GymWoman; кудрявая девушка справа в кадре — со стороны −X, char GymGuy = WomanB без очков).

**Throne** (чёрная пустота, прожектор):
* Чёрная коробка-комната (стены/пол без отражений), пол Y=0 глянцево-чёрный.
* Трон стоит на подиуме (верх подиума Y=0.8, подиум выступает вперёд до z≈-3.5, по ширине x±4) — стопы сидящего коня стоят на подиуме.
* Трон в (0,0,0), лицом в −Z: **верх сиденья Y=2.2**, сиденье z∈[-1.3,0.6], ширина 3.2; спинка z≈0.6…1.1 до Y≈8.5, корона сверху до Y≈10.5; подлокотники x=±1.9, верх Y≈3.4. Золотая резная рама, красный бархат.
* Прожектор сверху (≈ (0,30,-2)) вниз на трон + видимый конус света (Beam), пылинки, золотые искры.

## Проверенные факты Roblox (исследование, октябрь 2026)

* Лучший свет: `Lighting.LightingStyle = Realistic` + `PrioritizeLightingQuality = true` (уже в файле). `Technology` устарел.
* Дальность локальных источников (Point/Spot/SurfaceLight) — максимум **120 студов**; Angle до 180. Тени от локальных источников только в Realistic.
* `ShadowSoftness` работает только в Realistic. `EnvironmentSpecularScale = 1` важен для золота/металла.
* Только один BlurEffect рисуется (самый большой Size). Постэффекты: Bloom, Blur, ColorCorrection, ColorGrading, DepthOfField, SunRays. Своих шейдеров нет (рыбий глаз — только широким FOV).
* `Terrain.Decoration` (анимированная трава на материале Grass) не меняется скриптами — задана в файле.
* Частицы: встроенные текстуры `rbxasset://textures/particles/sparkles_main.dds`, `fire_main.dds`, `smoke_main.dds`, `forcefield_glow_main.dds`, `explosion01_core_main.dds`, а также `rbxasset://textures/sparkle.png`, `glow.png`, `whiteCircle.png`. `ParticleEmitter.LightInfluence` у созданного кодом = 0 (светится сам), `LightEmission = 1` — аддитивно.
* Beam для светового столба: `FaceCamera = true`, `LightEmission = 1`, `LightInfluence = 0`, прозрачность через NumberSequence; Attachment0/1 должны быть в Workspace.
* KeyframeSequence: сглаживание позы действует на сегмент ОТ этого ключа к следующему; Weight=0 — контейнер; CubicV2 In/Out — как TweenService.
