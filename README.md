# 🚨 AMBER ALERT: Hollow Creek (Roblox)

Кооперативный хоррор по формуле **Amber Alert**: днём собираешь яблоки и готовишь дом, в 21:00 по телевизору
идёт экстренное оповещение о сбежавшем пациенте, ночью он врывается в дом и охотится. Выживи все ночи.

До 8 игроков на сервере, один дом на улице Maple Court, 10 оригинальных пациентов — у каждого **одно правило**,
которое нужно понять и соблюдать. Дизайн-документ: [`docs/GDD.md`](docs/GDD.md).

## Как открыть

1. Скачай файл **`AmberAlert.rbxl`** из корня репозитория.
2. Открой его в **Roblox Studio** (File → Open from File).
3. Нажми **Play** (F5). Один игрок тоже может играть: нажми **READY** в лобби.
   Для теста с друзьями: вкладка **Test → Clients and Servers**, 2–4 игрока → Start.

> Сохранения (Амбер, опыт, перки) работают только в опубликованной игре. В неопубликованном файле игра
> работает **без сохранений** и пишет об этом (это нормально). Чтобы включить: опубликуй место
> (File → Publish to Roblox) и включи *Game Settings → Security → Enable Studio Access to API Services*.
>
> В Studio отряд стартует с $3000 (`Config.Economy.StudioStartingCash`), чтобы быстро проверить магазин.

## Как играть

1. **Лобби** — полицейский блокпост. Нажми **READY**, проголосуй за сложность (Easy 5 ночей, Normal 8, Hard 12, Nightmare 15).
2. **День (60 с)** — собирай яблоки на заднем дворе (`E`), продавай Рэю в гараже, покупай доски, ловушки, батарейки.
   Заколачивай окна (подойди к окну с досками), запирай входные двери (`F`).
3. **21:00 — оповещение** — телевизор в гостиной и баннер на экране объявляют, кто идёт, и его **правило**. Читай.
4. **Ночь (100–180 с)** — выключай свет, пригибайся (`C`), прячься в шкафах (`E`) и задерживай дыхание (`E` в шкафу),
   когда он рядом. Пойманный игрок падает — напарник поднимает за 4 с (`E`), иначе через 60 с его «забирают».
5. **06:00 — рассвет** — пациент уходит, отряд получает Амбер и опыт. Следующий день.
6. Пережил все ночи — победа, бонус Амбера; все забраны — поражение. Амбер тратится на перки в лобби.

### Управление

| Действие | ПК | Телефон / геймпад |
|---|---|---|
| Бег | `Shift` | кнопка «Sprint» / `L3` |
| Присесть | `C` / `B` | кнопка / `B` |
| Фонарик | `F` | кнопка / `Y` |
| Взаимодействие (двери, шкафы, яблоки, свет, магазин) | `E` | подсказка на экране / `X` |
| Запереть входную дверь | `F` у двери | подсказка |
| Выбрать предмет | `1`–`4`, колесо | тап по слоту |
| Применить предмет (ловушка, оружие, батарейки) | ЛКМ | кнопка «Use» / `R2` |
| Выбросить предмет | `Backspace` | кнопка / `X` |
| Задержать дыхание (в шкафу) | удерживать `E` | кнопка / `A` |
| Выйти из шкафа | `E` | кнопка |
| Пропустить оповещение | кнопка на экране (голосование) | кнопка |

## Что внутри

- **Один класс ИИ** со состояниями вход → обход → расследование шума → погоня по прямой видимости → поиск → уход на рассвете.
  Никаких телепортов и «телепатии»: без видимости и шума пациент знает только общую зону отряда.
- **Режиссёр напряжения**: пики 3–5 с, затем 30–45 с передышки, пока пациент «за кулисами» в дальней комнате.
- **Свет как механика**: в тёмной комнате дальность зрения пациента 14 вместо 40 стадов; фонарик, направленный на него, выдаёт тебя.
- **Укрытия с дыханием**: пациент рядом — дыхание тратится, задержи его (6 с, потом пауза). Тот, кто видел, как ты залез, откроет шкаф.
- **Честный звук**: шаги и голоса пациентов всегда настоящие (3D-звук на теле), телеграфы (стук, щелчок, мигание ламп) идут до угрозы.
- Процедурный R15-риг пациентов на анимациях Roblox, без текстур и крови (рейтинг «Mild fear»).
- Локализация EN/RU по языку игрока, интерфейс под телефон и ПК, настройки яркости/звука/head-bob.

## Где что менять

- **Баланс, цены, фазы, движение, укрытия** — `src/shared/Config.luau`
- **Ростер пациентов** (правила, скорости, HP, внешность) — `src/shared/Inmates.luau`
- **Тексты и оповещения (EN/RU)** — `src/shared/Locale.luau`
- **Звуки (ID)** — `src/client/Controllers/Sounds.luau` и `src/server/Services/ServerSounds.luau`
- **Карта** — генерируется скриптом `tools/gen_map.luau` (контракт имён: `docs/MapContract.md`)
- **Бейджи и геймпассы** — `Config.Badges` / `Config.Passes` (впиши ID после публикации; 0 = выключено)

В Studio скрипты лежат в `ServerScriptService/Server`, `ReplicatedStorage/Shared`, `StarterPlayer/StarterPlayerScripts/Client`.

## Перед публикацией

- Название: «Amber Alert: Hollow Creek [HORROR]». Иконка: фургон под единственным горящим фонарём, крупный заголовок.
- Опросник контента: **Fear — Mild/Repeated, Violence — Mild/Occasional, Blood — none**.
- Включи *Enable Studio Access to API Services* для сохранений, создай бейджи/пассы и впиши их ID в `Config`.
- Описание: первая фраза — что делать; предупреждение о вспышках и скримерах; управление; список обновлений.
