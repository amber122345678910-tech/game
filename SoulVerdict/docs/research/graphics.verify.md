## Important facts the report missed

1. **Pin Rojo ≥ 7.7.1 (CLI and plugin).** Only from 7.7.1 does the reflection database (v741) mark LightingStyle and PrioritizeLightingQuality ReadWrite.
   - NotScriptable properties stay `"Scriptability": "None"` in the Rojo database. This covers Terrain.Decoration, GrassLength, Workspace.ExpandedTerrain and the streaming radii. They can only reach the place through `rojo build` output or by hand in Studio, never through `rojo serve`.
2. **`Instance.new` defaults differ from Studio-insert defaults.** Code must set these explicitly:
   - ParticleEmitter.LightInfluence = 0
   - Highlight fill is red at 0.5 transparency
   - SpecialMesh.MeshType = Head
   - Beam.LightInfluence = 0
3. **Studio MCP details:**
   - `upload_image` uploads images from HTTP URLs to the Roblox asset server and returns asset IDs. The local-file tool is `store_image`.
   - `search_asset` and `insert_asset` reach the Creator Store.
   - Every call takes a `studio_id`, and `execute_luau` takes `datamodel_type` (Edit, Client or Server).
   - Consequence: if the owner enables MCP, the "no uploads" constraint can be lifted.
   - The server is a local **stdio** process on the owner's PC, so this cloud session cannot connect to it. Claude Code has to run on the same PC as Studio.
   - Whether `execute_luau` in Edit mode has PluginOrOpenCloud or PluginSecurity rights (enough to set LightingStyle or MaterialVariant maps) is UNVERIFIED.
4. **Loading Roblox's material textures at runtime may fail.** `AssetService:CreateEditableImageAsync` only loads images that are owned by or explicitly shared with the experience owner, the Studio user or the player. Loading Roblox's material texture IDs to feed `CreateSurfaceAppearanceAsync` may therefore throw; whether Open Use counts as shared for this API is UNVERIFIED. Images drawn entirely in code avoid the issue. [CD EditableImage.yaml]
5. **Extra APIs in the dump:**
   - `GeometryService:GenerateFragmentSites` (needed by FragmentAsync).
   - `GeometryService:BakeToMeshAsync`: undocumented, avoid.
   - `GeometryService:CreateBasicMeshPart`: needs the InternalTest capability, so it is unusable.
   - `AssetService:CreateTextureAsync`: undocumented.
   - `AssetService:ComposeDecalAsync(decal, layers)`.
6. **The creator-docs YAML hides split read/write capabilities.** For example, LightingStyle shows only "Environment". Always check `Capabilities.Write` in the API dump; 29 properties currently have Write = PluginOrOpenCloud.
