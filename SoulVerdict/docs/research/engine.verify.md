# Fact-check: "Roblox engine APIs for a code-only Rojo/Luau Undertale-style game"

## How this was checked

- **Two limits on this check:**
  - `create.roblox.com` did not resolve from this session.
  - The shared WebSearch budget for this turn (200 calls) was already used up, so every search returned "budget used up".
  - So no DevForum, newsroom or search-engine pages were read. Announcement dates and forum-only claims could not be re-checked.
- **Sources used instead.** Everything was read directly from `raw.githubusercontent.com`, which is reachable, on 2026-11-01:
  - **DOCS:** `Roblox/creator-docs` main branch, which is the source of create.roblox.com.
    - Each `https://create.roblox.com/docs/reference/engine/<kind>/<Name>` cited below was read from `https://raw.githubusercontent.com/Roblox/creator-docs/main/content/en-us/reference/engine/<kind>/<Name>.yaml`.
    - Guide pages were read from `.../content/en-us/<path>.md`.
  - **DUMP:** the live client API dump, version `0.745.0.7451137` (`version-7062aec9dbe74b14`), at https://raw.githubusercontent.com/MaximumADHD/Roblox-Client-Tracker/roblox/Full-API-Dump.json. It gives exact names, signatures, security levels, Deprecated/PreferredDescriptorName tags and capabilities.
  - **CLIENT:** https://raw.githubusercontent.com/MaximumADHD/Roblox-Client-Tracker/roblox/scripts/PlayerScripts/StarterPlayerScriptsCommon/RbxCharacterSounds.lua
  - **ROJO:** https://raw.githubusercontent.com/rojo-rbx/rojo/master/CHANGELOG.md
  - **RBXDOM:** https://raw.githubusercontent.com/rojo-rbx/rbx-dom/master/patches/workspace.yml, `.../patches/starter-player.yml` and `.../rbx_reflection_database/CHANGELOG.md`
- Where DOCS and DUMP disagree, both are given.

Source: https://create.roblox.com/docs/input/input-action-system, DUMP.

## Important facts the report missed

1. **The Avatar Joint Upgrade is on by default for new experiences.** Unless the owner sets `StarterPlayer.AvatarJointUpgrade = Disabled`, R15 player rigs spawn with AnimationConstraints. Joint code must handle both joint types. Before layering procedural animation, check `Animator.EvaluationThrottled`.
2. **Server Authority restrictions** (https://create.roblox.com/docs/projects/server-authority):
   - On predicted instances, an attribute only replicates if it is among the **first 64 attributes**, its **name is ≤ 50 characters**, and a **string value is ≤ 50 characters**.
   - InputContexts must be descendants of the **Player**.
   - Use `time()` in simulation code; it is synchronized and rolls back. `tick`, `os.time` and `os.clock` are not.
   - `Destroy()` and re-parenting are not allowed inside bound functions.
   - Tools are not fully supported.
   - RemoteEvents are not ordered relative to property and attribute replication when NextGenerationReplication is on.
3. **Further RunService APIs exist:** `BindToAnimation`, `BindToSimulationParallel`, `BindToAnimationParallel`, `GetPredictionStatus`, `IsResimulating`, and the `Misprediction` and `Rollback` events (DUMP).
4. **Spatial queries:** `GetPartBoundsInBox` and `GetPartBoundsInRadius` test **bounding boxes**, which are inaccurate for rotated or round parts. Use `GetPartsInPart` for exact hurtbox tests (WorldRoot DOCS).
5. **Editable APIs:**
   - Check for nil as well as wrapping in pcall, because the create calls return nil when the memory budget is exhausted.
   - `CreateDataModelContentAsync` returns a status enum; check for `StorageLimitExceeded`. Its DOCS mention a *server* storage budget.
   - Whether baked content replicates is still UNVERIFIABLE.
6. **Asset-free visual tools the report did not list (no beta label in DOCS):**
   - `UIShadow` adds blurred, spread, inset or text shadows and glows under any UI object. Properties: `BlurRadius`, `Spread`, `Offset`, `Inset`, `Mode` (Shape/Text), `ZIndex`, `ShowBehindParent`. It works with UICorner and UIGradient.
   - `ColorGradingEffect.TonemapperPreset` (Default or Retro) must be parented to Lighting; only the most recently parented instance applies.
   - `Path2D` also exists.
   - Sources: https://create.roblox.com/docs/reference/engine/classes/UIShadow, https://create.roblox.com/docs/reference/engine/classes/ColorGradingEffect.
7. **DataStore extras:**
   - `DataStoreService:SetRateLimitForRequestType(requestType, baseLimit, perPlayerLimit)` caps each server's share of the budget.
   - Studio Run mode has separate, lower static limits.
   - A write that reports failure may still have succeeded on the backend; confirm with a read.
8. **Input and character settings:**
   - `Workspace.PlayerScriptsUseInputActionSystem` (RolloutState, RobloxScriptSecurity) controls whether the default PlayerScripts use IAS.
   - `StarterPlayer.LuaCharacterController` takes `Enum.CharacterControlMode`: Default, Legacy, NoCharacterController, LuaCharacterController.
   - `Workspace.PlayerCharacterDestroyBehavior` auto-destroys replaced characters and leaving Player objects.
   - `UserInputService.ModalEnabled` is deprecated; use `GuiService.TouchControlsEnabled`.
