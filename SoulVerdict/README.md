# SOUL VERDICT

Оригинальная фанатская игра для Roblox по мотивам UNDERTALE в жанре «1 монстр против команды людей».
Один игрок становится **Сансом** (одна из трёх версий), остальные — **павшими детьми** с семью чертами души.
Без доната: всё открывается игрой.

> Некоммерческая фанатская игра, не связана с Тоби Фоксом. UNDERTALE © Toby Fox. Underfell — фанатская AU её авторов.
> Эклипс Санс — оригинальный персонаж этой игры.

**Доска стилей** (выбери тему меню, графику, стиль персонажей и любимые карты — я сделаю их стандартными):

## Как открыть и поиграть (нужен компьютер)

Roblox Studio работает только на **Windows или Mac**.

1. Скачай файл **`SoulVerdict/SoulVerdict.rbxl`** из этой ветки репозитория (`ccr-94709699-94udct`).
2. Открой его в **Roblox Studio** (File → Open from File).
3. Для красивой картинки: `File → Studio Settings → Rendering → Editor Quality Level` = максимум.
4. Нажми **Play**.

### Чек-лист первого запуска
1. В окне **Output** должны быть строки `server started with ... services` и `client started with ... controllers`
   и **не должно** быть строк `Init failed`, `Start failed`, `Failed to load`. Если есть — скопируй мне первую красную ошибку.
2. Появится титульный экран над лобби. Нажми **PLAY**: камера идёт за персонажем, `Ctrl` включает и выключает прицельную камеру.
3. В лобби: статуи персонажей на подиумах («Примерить» — сменить себя на этого персонажа), манекены для тренировки,
   таблицы лидеров, магазин и задания.
4. **Практика** (портал или кнопка в лобби): бой против ботов. Проверь все способности, Коробку Вердикта (F у монстра),
   падение и поднятие.
5. **Админ-панель** (кнопка с короной **ADMIN**): начать раунд одному, стать любым персонажем, бессмертие, без
   перезарядки, финальная фаза, «Коллапс», конец раунда → экран наград. Подробно — раздел «Админ-панель» ниже.
6. Мультиплеер: вкладка **Test → Clients and Servers**, 2–3 игрока → **Start**: голосование за карту, выбор монстра,
   интро, раунд, награды у всех.

Команды в чате (в Studio или у владельца): `/admin` (открыть админ-панель), `/practice`, `/skip`, `/final`, `/collapse`,
`/end`, `/map <карта> now`, `/dummy`, `/ult`. Если они не работают: `TextChatService → ChatVersion = TextChatService`.

## Как опубликовать
1. `File → Publish to Roblox` → новая игра.
2. `Game Settings → Security → Enable Studio Access to API Services` — чтобы сохранялся прогресс.
3. Готово. Игру можно открыть в Roblox, в том числе на телефоне.

### Как обновить уже опубликованную игру (новая версия файла)
1. Скачай новый `SoulVerdict.rbxl` и открой его в Studio (`File → Open from File`).
2. `File → Publish to Roblox As…` → выбери **свою уже существующую игру** → её место (place) → **Overwrite**.
   Название, иконка, настройки игры и сохранённый прогресс игроков останутся.
3. На телефоне полностью выйди из игры и зайди заново: старый сервер закроется, и ты попадёшь в новую версию.

## Админ-панель (тестировать одному)

Видна **только админам**: владельцу игры (тот, кто опубликовал; у игры группы — владелец группы), владельцу
приватного сервера и всем в Studio. Открыть: кнопка с короной **ADMIN** в лобби, кнопка **ADMIN** в главном меню
или команда `/admin` в чате.

| Вкладка | Что можно |
|---|---|
| **МАТЧ** | **Начать сейчас**: выбираешь сторону (человек или монстр) и персонажа — раунд стартует сразу, за другую сторону играют боты. Режим «играть одному» (раунд против ботов начинается сам после каждого возвращения в лобби), пропустить фазу, финальная фаза, «Коллапс», закончить раунд (победа людей или монстра), выбрать карту, добавить бота-человека или бота-монстра, убрать ботов, поставить манекены |
| **Я** | стать любым из 10 персонажей, бессмертие, без перезарядки, скорость ×1–×3, лечение (и подъём), полная ульта, сброс перезарядок, телепорт в лобби или на арену |
| **ПРОГРЕСС** | +золото, +уровни, открыть все наборы и скины, сбросить профиль (с подтверждением) |
| **ТЕСТ** | Коробка Вердикта на ближайшего (нужно быть монстром), урон себе, карма (KR) себе, обнулить уклонения монстра |

Важно: обычный раунд по правилам всё равно требует 2 игроков. Когда ты один, «Начать сейчас» и режим «играть одному»
запускают такой же раунд, но вместо второго игрока — боты (награды как за практику, ×0.25).

Дать админку друзьям: в Studio открой `ReplicatedStorage → Shared → Config`, внизу впиши их UserId
(число из ссылки профиля `roblox.com/users/<UserId>/profile`): `Config.Admins = { 123456789, 987654321 }`,
потом опубликуй заново. Или пришли мне ID — впишу сам.

### Телефон
Меню и интерфейс подстраиваются под экран: учитывают верхнюю панель Roblox и вырез камеры, перестраиваются при
повороте телефона, а интерфейс лобби прячется, пока открыто меню.

## Управление

| Действие | Клавиатура и мышь | Геймпад | Телефон |
|---|---|---|---|
| Атака | ЛКМ | RT | кнопка |
| Способности | Q / E / R / T | X / Y / B / вверх | кнопки |
| Блок и парирование (люди) / Коробка Вердикта (монстр) | F | LB (держать) | кнопка |
| Ульта монстра | G | LT+RT | кнопка |
| Ульта людей | R | LT+RT | кнопка |
| Рывок / мобильность | Shift | RB | кнопка |
| Прицельная камера вкл/выкл | Ctrl / Alt | правый стик | — |
| Эмоции (колесо) | B | вниз | кнопка |
| Меню | M | Select | кнопка сверху |
| Поднять упавшего союзника | G (подсказка над ним) | — | кнопка подсказки |

В настройках есть **«Быстрый каст»** (по умолчанию: способность срабатывает сразу) и режим
«зажми — прицелься — отпусти», а также инверсия камеры, чувствительность, FOV, тряска камеры, громкость и язык.

## Как сделать игру ещё лучше (по желанию)

1. **HD-черепа** (гладкие черепа Сансов и Гастер-бластеров вместо собранных из деталей):
   - вариант А: `Game Settings → Security → Allow Mesh / Image APIs` (Roblox может требовать проверку возраста/ID владельца);
   - вариант Б, без проверки: `File → Import 3D` → файлы из `SoulVerdict/assets/meshes/` → положить в `ReplicatedStorage/SV_Meshes`,
     имена не менять. Подробно: `docs/HD_MESHES.md`.
2. **Музыка и звуки.** Сейчас играют только встроенные звуки Roblox (шаги, прыжки), остальное беззвучно.
   В Studio открой `Toolbox → Creator Store → Audio`, выбери бесплатные треки (музыку из Undertale использовать нельзя —
   её удалят), скопируй ID и пришли мне: я вставлю их в `src/shared/Audio.luau`. Нужны: музыка лобби и 5 карт,
   финальная фаза, Коробка Вердикта, победа/поражение и звуки атак.
3. **Подключить меня к твоему Studio.** В Studio `Assistant → Manage MCP Servers → Enable Studio as MCP server`,
   на компьютере — приложение Claude с Remote Control. Тогда я сам запущу игру в твоём Studio, сделаю скриншоты
   и подкручу графику по реальной картинке.
