# UNDERTALE: SOUL VERDICT

Оригинальная фанатская игра для Roblox в жанре «1 монстр против команды людей» по мотивам Undertale и его AU.
Один игрок — **Санс** (одна из трёх версий), остальные — **люди с душами** (7 классов по 7 чертам души).
Без доната: всё открывается игрой.

> Статус: в разработке. Этот файл обновляется по мере готовности систем.

## Как открыть и поиграть (нужен компьютер)

Roblox Studio работает только на **Windows или Mac** (не на телефоне).

1. Скачай файл `SoulVerdict/SoulVerdict.rbxl` из этой ветки репозитория.
2. Открой его в **Roblox Studio** (двойной клик или File → Open from File).
3. Нажми **Play** (F5).
   - Если ты один: в лобби открой меню → **Практика** (против ботов), или подойди к манекенам в тренировочной зоне.
   - Чтобы проверить мультиплеер: вкладка **Test → Clients and Servers**, выбери 2–4 игрока → **Start**.
4. Для красивой картинки в Studio: `File → Studio Settings → Rendering → Editor Quality Level` = максимум.

## Как опубликовать

1. `File → Publish to Roblox` → создай новую игру.
2. `Game Settings → Security → Enable Studio Access to API Services` — включи, чтобы работали сохранения прогресса.
3. Готово: игру можно открыть в Roblox (в том числе на телефоне).

## Как ты можешь сделать игру ещё качественнее

Эти шаги необязательны, без них всё работает:

1. **HD-модели черепов** (гладкие черепа Сансов и Гастер-бластеров вместо собранных из деталей):
   - вариант А: `Game Settings → Security → Allow Mesh / Image APIs` (Roblox требует, чтобы владелец игры прошёл проверку возраста/ID);
   - вариант Б (без проверки): `File → Import 3D` → выбери файлы из `SoulVerdict/assets/meshes/` → положи их в папку `ReplicatedStorage/SV_Meshes`, не меняя имена.
2. **Музыка и звуки**: в Studio открой `Toolbox → Creator Store → Audio`, выбери бесплатные треки (музыку из Undertale использовать нельзя — её удалят), скопируй их ID и пришли мне — я вставлю их в игру.
3. **Подключить меня к твоему Studio** (максимальный буст): в Studio `Assistant → Manage MCP Servers → Enable Studio as MCP server`, а на компьютере — приложение Claude с Remote Control. Тогда я смогу сам запускать игру в твоём Studio, делать скриншоты и править графику по картинке.
